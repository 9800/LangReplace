# LangReplace

یک ابزار سبک و سریع برای تبدیل چیدمان کیبورد فارسی و انگلیسی در ویندوز.

## ویژگی‌ها

- ✅ تبدیل چیدمان کیبورد (FA ↔ EN)
- ✅ کلیدهای میانبر سراسری (F10, F6, Shift+F10)
- ✅ جستجو در گوگل (Ctrl+G)
- ✅ ترجمه متن (Ctrl+T)
- ✅ تولید QR Code (Ctrl+M)
- ✅ آیکون System Tray
- ✅ سبک و کم‌مصرف (زیر 500KB)
- ✅ بدون نیاز به نصب (Portable)

## نصب

1. فایل `LangReplace.exe` را دانلود کنید
2. اجرا کنید
3. تمام!

## کلیدهای میانبر

| کلید | عملیات |
|---|---|
| F10 | تبدیل انگلیسی به فارسی |
| F6 | تبدیل فارسی به انگلیسی |
| Shift+F10 | تبدیل با حفظ بزرگی حروف |
| Ctrl+G | جستجو در گوگل |
| Ctrl+T | ترجمه متن |
| Ctrl+M | تولید QR Code |
